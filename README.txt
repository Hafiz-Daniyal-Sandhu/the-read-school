THE READ SCHOOL WEBSITE — ONLINE ADMISSIONS + SOCIAL LINKS

Upload all files to a public GitHub repository and enable GitHub Pages via Settings > Pages > Deploy from a branch > main > /(root).

ONLINE ADMISSIONS SETUP
1. Sign into the Google account that should manage school admission data.
2. Open https://script.google.com and create a project.
3. Paste the code from Google_Apps_Script_Code.gs.
4. Run setup() once and approve permissions. It creates a Google Sheet.
5. Deploy > New deployment > Web app; Execute as Me; Who has access: Anyone.
6. Copy the deployed URL ending /exec and replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE in index.html.
7. Upload the updated index.html to GitHub and test a sample admission. Confirm the email and Sheet receive it.
